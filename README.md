# Amazon — Pedro Cabral

Este projeto acadêmico foi desenvolvido durante o curso Figma Turbo, como parte da disciplina de Frameworks. Utilizando HTML, CSS, JavaScript, Vue 3.5.42 e Vite, o objetivo é reproduzir a interface da Amazon, explorando seus elementos visuais e funcionalidades.

A aplicação apresenta uma seleção de produtos e uma página dedicada ao Nintendo Switch 2, colocando em prática os conhecimentos adquiridos em desenvolvimento web e na utilização de frameworks modernos.

## Executar

```sh
npm install
npm run dev
```

## Gerar o site

```sh
npm run build
npm run preview
```

Os componentes ficam em `src/components`, os produtos em `src/dados` e o CSS em `src/assets/main.css`. O carrinho e os formulários são demonstrativos.

Marcas e imagens pertencem aos respectivos titulares. Projeto sem vínculo com a Amazon.
